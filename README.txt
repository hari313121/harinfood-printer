HARINFOOD PRINTER (pembungkus WebView untuk HARINFOOD POS)

Cara membuat APK tanpa PC (lewat GitHub):
1. Buat repository baru di GitHub, unggah SELURUH isi folder ini (termasuk folder .github).
2. Buka tab "Actions" -> pilih "Build APK" -> "Run workflow" (atau otomatis berjalan setelah unggah).
3. Setelah selesai (hijau), buka run tersebut -> bagian "Artifacts" -> unduh "HarinfoodPrinter-apk" -> ekstrak -> pasang app-debug.apk di HP kasir.

Versi 1.1: tombol "Aktifkan GPS" di aplikasi memunculkan dialog sistem untuk menyalakan lokasi, dan izin lokasi untuk halaman web sudah ditangani.
Catatan: pasang versi baru di atas versi lama (applicationId sama), tidak perlu hapus dulu.
